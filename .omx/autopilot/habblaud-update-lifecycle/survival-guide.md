# Survival guide — Habblaud update lifecycle

The user authorized autopilot with subagents, AIOffice-only updates, and mobile Cloudflare access. The shared checkout has extensive pre-existing edits; preserve them and do not reset, clean, stash, commit, push, publish, or deploy. The updater only installs official AIOffice releases into a clean managed checkout. Mobile login keeps the random Quick Tunnel and local QR; the panel issues a temporary one-use code. Never bypass Chrome Safe Browsing or ask the user to enter the code when the browser marks the host dangerous. Session keys include a fresh per-listener nonce. Code gates passed: root/app typecheck, build, i18n, diff check. Automated tests, live browser QA, and real tunnel/login remain unverified. The active service was not restarted; a normal restart is needed to load these local changes. Continue from `checkpoint.md` and `validation.md`.
