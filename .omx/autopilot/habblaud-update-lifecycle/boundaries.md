# Boundaries — Habblaud update lifecycle

- **NEVER:** reset, clean, stash, or overwrite the pre-existing worktree; auto-commit; push; merge; publish; deploy; remove data; auto-apply upstream code; send prompts or interrupt live sessions.
- **DANGER:** Only official AIOffice tags may install. Keep the installer blocked for dirty/unsupported roots and active PTYs; use external staging, cooperative shutdown, exact nonce/PID/version health confirmation, and preserved rollback artifacts. Preserve existing remote TLS assets; do not provision VPN/firewall/CA trust automatically. Remote login uses a five-minute one-use code from the local panel; session cookies use a fresh key nonce for each listener. Never expose the local HTTP port or bypass browser Safe Browsing.
- **ROLLBACK:** Task branch `codex/habblaud-011-integration-20261013`, created at prior HEAD `2be3dc6a748ed4b75d93c35277a891428eaf6fb0`; pre-existing changes remain unstaged/uncommitted. Revert only task-owned edits if needed; never reset the shared worktree.
- **VERIFY:** Compare upstream v0.10.0..v0.11.0; run available build/typecheck/i18n/diff checks and adversarially review installer/remote boundaries. Release publish and updater execution are not validation steps.
- **Decision boundary:** The user approved maintainers updating the base and end users updating AIOffice. Treat upstream version as maintenance metadata; route user notices to AIOffice releases. Defer changes that expand access, execution, or data collection.
- **Launcher/tunnel boundary:** Never terminate the current service or broad `node.exe` processes. Do not add a dynamic Cloudflare hostname to Vite dev `allowedHosts`; the correct route is the built client via `start:office`. Do not bypass browser Safe Browsing. Quick Tunnel is temporary; stable naming needs a domain controlled by the user.
- **Mobile-control boundary:** Configure/Start explicitly enables the HTTPS listener from local Settings. Code issuance is loopback + Origin protected; the remote listener cannot control the tunnel or issue codes. No default permissions beyond read-only. Never return a login code except from the local issuance endpoint, and never persist a code, password, private key, or CA private key. Stop closes the listener and invalidates codes/sessions. No automatic port forwarding, firewall, or VPN changes.
- **Release identity boundary:** Display an AIOffice version/update only when the release repo is exactly `IAPro-Community/AIOffice`; do not surface numeric versions or repository links from Habblaud/unknown channels.
