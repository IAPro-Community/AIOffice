# Boundaries — Habblaud update lifecycle

- **NEVER:** reset, clean, stash, or overwrite the pre-existing worktree; auto-commit; push; merge; publish; deploy; remove data; auto-apply upstream code; send prompts or interrupt live sessions.
- **DANGER:** Only official AIOffice tags may install. Keep the installer blocked for dirty/unsupported roots and active PTYs; use external staging, cooperative shutdown, exact nonce/PID/version health confirmation, and preserved rollback artifacts. Remote access stays disabled until explicit operator setup and must use HTTPS/password auth/allowlist. Never expose the local HTTP port or provision VPN/firewall/CA trust automatically.
- **ROLLBACK:** Task branch `codex/habblaud-011-integration-20261013`, created at prior HEAD `2be3dc6a748ed4b75d93c35277a891428eaf6fb0`; pre-existing changes remain unstaged/uncommitted. Revert only task-owned edits if needed; never reset the shared worktree.
- **VERIFY:** Compare upstream v0.10.0..v0.11.0; run available build/typecheck/i18n/diff checks and adversarially review installer/remote boundaries. Release publish and updater execution are not validation steps.
- **Decision boundary:** The user approved maintainers updating the base and end users updating AIOffice. Treat upstream version as maintenance metadata; route user notices to AIOffice releases. Defer changes that expand access, execution, or data collection.
- **Mobile-control boundary:** Enable an HTTPS listener only after an explicit owner action in the local Settings UI. Reject remote/CSRF requests to control routes. No default permissions beyond read-only. Never return a password, hash, private key, or CA private key. Stop closes the listener now and persists disabled state while retaining its hashed configuration. No automatic port forwarding, firewall, or VPN changes.
- **Release identity boundary:** Display an AIOffice version/update only when the release repo is exactly `IAPro-Community/AIOffice`; do not surface numeric versions or repository links from Habblaud/unknown channels.
