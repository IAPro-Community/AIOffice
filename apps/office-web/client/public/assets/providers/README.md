# Marcas dos provedores

Estes arquivos são servidos localmente e aparecem apenas para identificar a ferramenta conectada.

- `claude.svg`: símbolo Claude baseado no ícone do Simple Icons, colorido para o tema oficial Claude. O ícone de referência também está disponível no aplicativo Claude.
- `codex.svg`: marca Codex do pacote comunitário `@lobehub/icons-static-svg`, distribuída em `asvg.app`; marcas OpenAI/Codex continuam pertencendo à OpenAI.
- `omp.svg`: cópia de `assets/icon.svg` do repositório `can1357/oh-my-pi`; licença MIT em `OMP-LICENSE.txt`.
- `opencode.svg`: símbolo OpenCode baseado no ícone do Simple Icons, com a cor clara usada sobre fundos escuros. Consulte também as [diretrizes oficiais de marca](https://opencode.ai/brand).

Fontes dos vetores: [Simple Icons — Claude](https://github.com/simple-icons/simple-icons/blob/develop/icons/claude.svg), [Simple Icons — OpenCode](https://github.com/simple-icons/simple-icons/blob/develop/icons/opencode.svg), [oh-my-pi — ícone](https://github.com/can1357/oh-my-pi/blob/main/assets/icon.svg) e [Codex — pacote de ícones](https://asvg.app/icons/codex).
